# Free Classroom Finder Project (Room Availability System)

A web-based system built using HTML, CSS, and JavaScript that helps users find free classrooms and check room availability at specific times.

## Project Overview

This project is designed to manage and display classroom availability based on time slots. Users can search for free rooms or check details of a specific room at a given time.

## Features

* Find free classrooms based on time slots
* Check room availability status
* Search specific room details
* Schedule-based system logic
* Clean and user-friendly interface
* Responsive design for all devices

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Select a time or room to check availability.
