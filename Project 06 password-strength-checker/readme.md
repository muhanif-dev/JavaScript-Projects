# Password Strength Checker Project

A simple and interactive Password Strength Checker built using HTML, CSS, and JavaScript.

## Project Overview

This project analyzes the strength of a user's password and provides real-time feedback based on password complexity. The goal is to help users create stronger passwords by checking factors such as length, uppercase letters, lowercase letters, numbers, and special characters.

## Features

* Real-Time Password Analysis
* Password Strength Indicator
* Weak, Medium, and Strong Password Detection
* User-Friendly Interface
* Responsive Design
* Instant Feedback While Typing

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Enter a password to see its strength analysis.
