# University Task Project – QR Code & Barcode Generator Website

A full multi-page web application built using HTML, CSS, and JavaScript that generates QR codes and barcodes for any link or text input.

## Project Overview

This project was developed as a university task. It allows users to generate QR codes and barcodes instantly by entering a name, text, or URL. The website also includes additional university-related pages, making it a complete structured web application.

## Features

* Generate QR Code from text or URL
* Generate Barcode from input data
* Instant code generation
* Multi-page website structure
* Responsive and clean UI design
* User-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* QR Code Library (e.g., QRCode.js)
* Barcode Library (e.g., JsBarcode)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Navigate to QR or Barcode generator pages.
5. Enter text or link to generate codes instantly.
