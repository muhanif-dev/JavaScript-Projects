# Weather App Project

A simple and interactive Weather App built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to search for any city and view real-time weather information. It fetches live weather data from an API and displays temperature, humidity, and weather conditions in a clean interface.

## Features

* Search Weather by City Name
* Real-Time Weather Data
* Temperature Display
* Humidity Information
* Weather Condition Description
* Responsive User Interface
* Clean and Modern Design

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Weather API (e.g., OpenWeatherMap)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Add your API key in the JavaScript file.
4. Run `index.html` in your browser.
5. Enter a city name to view weather details.
