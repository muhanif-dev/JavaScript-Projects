# Dark Mode / Light Mode Toggle Project

A simple theme-switching web application built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to switch between Light Mode and Dark Mode with a single click. The application dynamically changes the website's appearance to provide a better viewing experience based on user preference.

## Features

* Light Mode Interface
* Dark Mode Interface
* One-Click Theme Switching
* Responsive Design
* Clean User Experience
* Beginner-Friendly Code Structure

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Learning Outcomes

This project helped me practice:

* DOM Manipulation
* Event Handling
* CSS Class Toggling
* Dynamic Styling
* Theme Management
* Frontend Development Fundamentals

## Project Structure

```text
project-folder/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Click the toggle button to switch between Dark Mode and Light Mode.
