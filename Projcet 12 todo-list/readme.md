# To-Do List Project

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to manage their daily tasks efficiently by adding, completing, and deleting tasks. The application provides a clean and user-friendly interface, making task organization simple and effective.

## Features

* Add New Tasks
* Mark Tasks as Completed
* Delete Tasks
* Dynamic Task Updates
* Responsive Design
* Clean User Interface
* Easy Task Management

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Learning Outcomes

* User Input Handling
* Frontend Development Fundamentals

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Enter a task in the input field.
5. Click the add button to create a task.
6. Mark tasks as completed or delete them when finished.
