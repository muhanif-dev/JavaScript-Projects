# Temperature Converter Project

A simple and interactive Temperature Converter built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin quickly and accurately. The application provides real-time conversions through a clean and easy-to-use interface.

## Features

* Celsius to Fahrenheit Conversion
* Celsius to Kelvin Conversion
* Fahrenheit to Celsius Conversion
* Fahrenheit to Kelvin Conversion
* Kelvin to Celsius Conversion
* Kelvin to Fahrenheit Conversion
* Instant Results
* Responsive Design
* User-Friendly Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Enter a temperature value.
5. Select the source and target temperature units.
6. View the converted result instantly.
