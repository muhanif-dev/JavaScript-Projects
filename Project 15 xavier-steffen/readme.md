# Xavier Blog Website Project

A multi-page long-form blog website built using HTML, CSS, and JavaScript as part of a university web development assignment.

## Project Overview

The Xavier Project is a structured blog website designed to display long articles in a clean and readable format. The focus of this project is on content organization, layout design, and user experience.

## Features

* Multi-page blog website
* Long-form article layout
* Clean typography and spacing
* Responsive design for all screen sizes
* Navigation menu for easy browsing
* Organized content structure

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Learning Outcomes

This project helped me practice:

* Multi-page website development
* CSS layout and typography design
* Responsive web design
* Content structuring for blogs
* UI/UX principles
* Frontend development fundamentals

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Navigate through different pages using the menu.
