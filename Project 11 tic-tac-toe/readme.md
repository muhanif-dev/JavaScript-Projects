# Tic Tac Toe Game Project

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Project Overview

This project is a browser-based implementation of the classic Tic Tac Toe game. Two players take turns marking spaces in a 3×3 grid with X and O. The game automatically checks for winning combinations and declares the winner or a draw when the game ends.

## Features

* Two-Player Gameplay
* Winner Detection
* Draw Detection
* Restart Game Option
* Interactive User Interface
* Responsive Design
* Smooth User Experience

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Game Rules

* Player 1 uses X
* Player 2 uses O
* Players take turns selecting empty cells
* Three matching symbols in a row, column, or diagonal win the game
* If all cells are filled without a winner, the game ends in a draw

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Take turns placing X and O on the grid.
5. The game automatically detects the winner or a draw.
6. Use the restart button to play again.
