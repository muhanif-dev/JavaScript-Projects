# Bill Tip Calculator Project

A simple and interactive Bill Tip Calculator built using HTML, CSS, and JavaScript.

## Project Overview

This project allows users to calculate the tip amount and total payable bill based on the entered bill amount and selected tip percentage. It is designed to provide quick and accurate calculations while offering a clean and user-friendly interface.

## Features

* Instant Tip Calculation
* Total Bill Calculation
* Easy User Input
* Responsive Design
* Clean User Interface
* Real-Time Results

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Enter the bill amount and tip percentage.
5. View the calculated tip and total bill instantly.
