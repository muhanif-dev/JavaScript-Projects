# JavaScript Mini Projects Collection

A collection of web development projects built using HTML, CSS, and JavaScript. These projects were developed to strengthen my frontend development skills, improve problem-solving abilities, and gain hands-on experience with real-world web applications.

## About This Repository

This repository contains multiple JavaScript projects ranging from beginner-friendly applications to more advanced utility tools, games, and university projects.

Each project focuses on different frontend development concepts such as:

* DOM Manipulation
* Event Handling
* API Integration
* Responsive Design
* Form Validation
* Game Logic Development
* Data Filtering
* User Interface Design
* Problem Solving

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

# Projects Included

## Utility Applications

### 1. Small Pop-up Project

A simple popup modal that can be opened and closed through user interaction.

### 2. Dark Mode / Light Mode Toggle

Switch between light and dark themes dynamically.

### 3. Password Strength Checker

Analyze password strength based on complexity and security requirements.

### 4. Bill Tip Calculator

Calculate tip amounts and total bills instantly.

### 5. Temperature Converter

Convert temperatures between Celsius, Fahrenheit, and Kelvin.

### 6. Ring Size Calculator

Calculate ring sizes based on user measurements.

### 7. Weather App

Fetch and display real-time weather information using API integration.
