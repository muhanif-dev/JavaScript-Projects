# Rock Paper Scissors Game Project

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Project Overview

This project is a web-based implementation of the classic Rock Paper Scissors game. Players compete against the computer by selecting Rock, Paper, or Scissors. The computer generates a random choice, and the application determines the winner according to the game rules.

## Features

* Play Against the Computer
* Random Computer Moves
* Instant Result Display
* Win, Lose, and Draw Detection
* Score Tracking
* Responsive User Interface
* Interactive Gameplay

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Learning Outcomes

This project helped me practice:

* DOM Manipulation
* Event Handling
* Conditional Statements
* Random Number Generation
* Game Logic Development
* Frontend Development Fundamentals

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a Draw

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Select Rock, Paper, or Scissors.
5. View the computer's choice and the game result instantly.
